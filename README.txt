LAN Pocket Guide — Dakar 2026 (web version)
============================================

Upload ALL of these files, side by side, to the hosting service:
  index.html              the guide
  sw.js                   makes the guide work offline
  manifest.webmanifest    lets phones install it like an app
  icon-192.png, icon-512.png, icon-maskable-512.png,
  apple-touch-icon.png, favicon-32.png     app icons

Do not rename the files or put them in a sub-folder.

Updating the guide later
------------------------
When you receive a new version, upload the new index.html AND the new sw.js
together (replace the old ones). Phones that already have the guide will show
"A new version of the guide is ready - Update" the next time they open it
with internet. The version number is shown at the bottom of the guide and in
"Review draft - about this guide".
